# Playbook

Learned rules from analytics. The Strategist agent (phase 5) rewrites this file weekly and
commits the diff, so the history of this file is the history of what the account learned.
Until there is data, these are priors, not findings.

## Format
- One idea per post. Split anything with two ideas into two posts.
- Every post ships with a visual unless it is a pure text take.
- Links go in the first reply, never the main post.

## Timing (ET)
- 08:45 paper of the day
- 12:30 take / build-in-public
- 17:00 second paper or curation
- Thu 09:00 weekly thread
- Apply 10-20 min of jitter to every slot.

## Topics currently favoured
- Agent orchestration, tool use, and their failure modes
- Inference cost and latency
- Evaluation methodology, especially critiques of it
- Anything with a number that contradicts the consensus

## Topics currently deprioritised
- Model release announcements with no technical detail
- Benchmark SOTA-by-0.3% papers
- Anything already covered in the last 14 days
